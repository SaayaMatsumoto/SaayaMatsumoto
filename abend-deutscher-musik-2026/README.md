# 「abend-deutscher-musik-2026」公演ページ

2026年10月に都城・宮崎で開催する、声楽とピアノの演奏会用の静的ページです。

## 公開パス

`/abend-deutscher-musik-2026/`

ビルド作業は不要です。リポジトリの GitHub Pages が公開されると、このディレクトリの `index.html` が上記のパスで表示されます。

## ファイル構成

```text
abend-deutscher-musik-2026/
├── index.html
├── css/
│   └── style.css
└── images/
    ├── og-image.jpg
    ├── piano.jpg
    └── soprano.jpg
```

## 公開前に差し替える情報

`index.html` 内の次の仮情報を、確定情報に置き換えてください。

- ［コンサートタイトル］
- ソプラノ、ピアノ各出演者の氏名
- 各出演者のプロフィール
- 都城公演、宮崎公演のお問い合わせ電話番号
- 都城公演、宮崎公演のチケット取扱店

氏名と公演タイトルは、本文だけでなく `<title>`、メタ情報、JSON-LD 内にもあります。

## 画像について

現在の `soprano.jpg` と `piano.jpg` は、人物写真が未提供であることを明確にするための、人物を含まない仮画像です。実際の出演者写真が用意できたら、同じファイル名の JPEG 画像に差し替えてください。表示比率は縦 4:5 を推奨します。

`og-image.jpg` は、共有時に使用する横長の仮画像です。差し替える場合は横 1.91:1 前後（例：1200 × 630ピクセル）を推奨します。

## 実装方針

- HTML と CSS のみを使用
- JavaScript、外部ライブラリ、ビルドシステムは不使用
- ページ内の CSS・画像参照はすべて相対パス
- スマートフォンを基準にしたレスポンシブ設計
- 2公演分の schema.org `MusicEvent` 構造化データを収録
- 既存サイトのルートファイルから独立
